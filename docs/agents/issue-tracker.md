# Issue tracker: Linear

Issues, specifications, and implementation tickets for Zara live in the Zara Linear workspace.

## Conventions

- Use the Zara team and its existing `ZAR-###` issue identifiers.
- Publish specifications as parent Linear issues.
- Publish implementation tickets as child or related issues in dependency order.
- Use native `blocked by` relationships for ticket dependencies.
- Apply `ready-for-agent` to specifications and tickets that require no additional human context.
- Keep matching records in `docs/Issue-Backlog.md` and issue-specific documents under `docs/Handovers/`.
- Every local issue record must include its Linear URL.
- Keep Linear status, local backlog status, and handover status synchronized.
- Do not treat GitHub pull requests as incoming triage requests.
