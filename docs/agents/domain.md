# Domain Docs

Zara uses a multi-context documentation layout.

## Required routing

1. Read `AGENTS.md`.
2. Read `docs/AGENT-START.md`.
3. Read `docs/CONTEXT-MAP.md`.
4. Follow the map to the global baseline and focused domain documents required for the task.
5. Read relevant system-wide ADRs under `docs/ADRs/`.
6. Read the active issue handover for implementation or issue work.

Use terminology defined by Zara's routed domain documentation in specifications, tickets, tests, and implementation work. Surface conflicts with existing ADRs instead of silently overriding them.
